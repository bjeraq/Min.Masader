# مِن مصادر (Min.Masader)

«مِن مصادر» — أخبارٌ بمصادرها: تقارير عربية موثّقة بمصادر متعددة وفيديوهات توضيحية، عن الكويت والخليج.

- الموقع: https://bjeraq.github.io/min.masader/
- كل خبر يذكر مصادره مع روابطها، ويفصل الخبر عن الرأي والتحليل.
- الرسوم في الفيديوهات مولّدة بالذكاء الاصطناعي أو مرسومة يدوياً، بدون علامات تجارية ولا وجوه مسؤولين حقيقيين.
